# SNOWISE DISCOVER

# 포함 기능

- 전체 참여 현황 및 참여 집중도
- 학과별 진단 및 A~D 유형화
- 분야별 프로그램 공급, 승인 구조
- 학과 유형별 운영 주체 이용 경로
- 2022~2024 이력 → 2025 신규 참여 Hit@K 오프라인 검증
- 학과, 학년, 관심 분야, 참여 이력 기반 추천 시뮬레이터

# 데이터 및 해석상 주의

- 앱은 사용자가 업로드한 과거 CSV를 처리하는 분석, 시연용 프로토타입이다.
- 추천 시뮬레이터는 과거 데이터의 프로그램 그룹과 사용자가 선택한 조건을 이용한 규칙 기반 시연이다. 실제 학생별 SNOWISE 추천 결과가 아니다.
- 모집 시작일, 마감일, 정원, 실시간 모집 상태 및 SNOWISE 노출, 클릭 로그는 데이터에 포함되어 있지 않다.
- Hit@K는 과거 승인 이력을 이용한 오프라인 평가값으로, 실제 서비스 전환율이 아니다.
- 자율 0회 비율은 제공 데이터에서 승인 기록이 관측된 학생-학년도 중 자율 비교과 승인이 0건인 비율이다. 전체 재학생의 미참여율로 해석하면 안 된다.
